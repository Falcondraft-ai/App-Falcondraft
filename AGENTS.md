# AGENTS.md

This repository is for the FalconDraft website.

## Core objective

Build a premium storytelling website for FalconDraft, an agency/service business that sells a complete, turnkey, personalized system for automating the creation of commercial proposals.

The main audience is architecture firms and similar businesses with complex proposal workflows.

## Main operating rule

When in doubt, prioritize:

- clarity over hype
- premium restraint over visual noise
- storytelling progression over generic marketing sections
- typography and spacing over decorative effects
- trust and business credibility over trendy AI aesthetics

## Stack

- Next.js App Router
- TypeScript strict
- Tailwind CSS
- Motion for UI animation
- GSAP only when advanced storytelling motion is justified
- Storybook
- Playwright

## Design direction

The website must feel:

- premium
- editorial
- strategic
- precise
- high-trust
- calm
- professional

The website must not feel:

- generic SaaS
- startup-template-like
- cheap
- noisy
- over-animated
- AI-generated

## Brand cues

Use the FalconDraft brand cues:

- deep navy
- restrained gold/copper accents
- clean document-oriented symbolism
- elegant composition
- strong visual hierarchy

## Content direction

The site should explain the transformation from:
manual, fragmented proposal creation

to:
a structured, personalized, controlled proposal system

## Quality rules

- No any
- No placeholder code
- No incomplete output
- No generic marketing filler
- Respect reduced motion
- Prefer transforms and opacity for motion
- Use clean component boundaries
- Keep page logic readable

## Workflow

For non-trivial tasks:

1. Identify the narrative arc
2. Propose the section order
3. Explain motion strategy
4. Implement fully
5. Suggest verification steps
