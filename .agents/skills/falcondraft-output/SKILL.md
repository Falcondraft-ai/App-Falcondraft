When generating FalconDraft UI, the output must feel complete, designed, and production-minded.

## Always

- output complete code for the requested scope
- use the project structure correctly
- keep components clean and typed
- ensure the result feels premium and intentional
- ensure sections are connected by narrative logic
- ensure responsive behavior is considered

## Never

- leave placeholder sections
- output generic SaaS marketing copy
- use lazy comments instead of implementation
- create repetitive cards without reason
- rely on decorative effects to fake quality

## Final self-check

Before finalizing, ask:
- does this feel like a real premium agency site?
- does it reflect FalconDraft's positioning?
- does it explain transformation clearly?
- does it avoid AI-generic visual patterns?
- does it preserve editorial quality and trust?
