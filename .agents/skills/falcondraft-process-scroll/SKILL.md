The FalconDraft website should include a strong vertical scroll storytelling section explaining the process.

## Core principle

The process must feel:
- clear
- progressive
- operational
- premium
- controlled

It should not feel:
- gimmicky
- overly technical
- timeline-template-like
- overloaded

## Recommended process structure

Use a 5-step process:

1. Audit current proposal workflow
2. Map reusable content, variations, and logic
3. Build the FalconDraft system
4. Adapt it to the firm's real methods and cases
5. Deploy and onboard the team

## Scroll behavior

Prefer:
- vertical progression
- active step emphasis
- sticky or semi-sticky reading experience when appropriate
- elegant transitions between steps
- progressive reveal of details

Avoid:
- too many moving parts
- parallax overload
- horizontal gimmicks
- over-animated diagrams

## Motion guidance

Use Motion for:
- text reveal
- active state transitions
- step emphasis
- smooth content changes

Use GSAP only if needed for:
- step choreography
- sticky progression
- one signature process moment

Always:
- keep it readable
- preserve narrative clarity
- support reduced motion

## Design guidance

The process section should feel like a premium methodology explanation, not a startup feature carousel.
